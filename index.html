PHP Native · MySQL · 2025 – 2026

Masalah

Analisis data gangguan penyulang masih manual, tersebar di file Excel, dan lambat untuk dijadikan laporan rutin bagi tim UP2D.

Pendekatan

Membangun basis data ternormalisasi untuk gangguan, penyulang, log aktivitas, dan kuesioner kepuasan, lengkap dengan dashboard analitik interaktif dan import data Excel.

Keamanan

Prepared statement (anti-SQL Injection), token CSRF, output escaping (anti-XSS), Content Security Policy, dan pengujian dengan OWASP ZAP dipetakan ke OWASP Top 10.

Hasil

Sistem berjalan di hosting produksi dengan autentikasi aman, rate limiting login, role-based access control, serta ekspor laporan otomatis ke Excel & PDF.
