SIADA

Sistem Informasi Otomatisasi Analisa Data Gangguan

Aplikasi web full-stack yang mengotomatisasi analisis data gangguan jaringan distribusi listrik, dari import data hingga laporan yang siap dipakai. Berawal dari dashboard monitoring di Google Sheets yang saya susun saat magang, lalu saya kembangkan menjadi sistem web utuh.

  • Fitur utama: import data Excel, dashboard analitik interaktif, dan pelaporan otomatis dalam format Excel dan PDF.
  • Keamanan aplikasi berlapis: prepared statement (anti SQL Injection), token CSRF, output escaping (anti XSS), Content Security Policy, dan header keamanan HTTP.
  • Memadukan latar belakang kelistrikan dengan rekayasa perangkat lunak, sehingga solusinya relevan dengan kebutuhan operasional industri kelistrikan.
